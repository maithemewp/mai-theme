# Changes

## 3.0.0 (unreleased)

* Added: The starter block theme for Mai Slots. Eight standard templates, five custom templates (Blank, Canvas, Wide, Narrow, With sidebar), and six template parts, with a locked Slot block for every Mai Slots location.
* Added: Two layout patterns for the Site Editor's Design panel, "Post: With sidebar" and "Archive: List".
* Added: `theme.json` tokens for colour, font size, spacing, fonts, line height, shadows, radius, and aspect ratios, with core's default presets removed.
* Added: The Alt Heading block style, on Heading and Paragraph.
* Added: Starter block CSS for the navigation overlay, Post Template cards, and the Search block.
* Added: Figtree, self-hosted.
* Added: Plumbing through the `maithemewp/mai-theme-core` package, including a dependency installer for Mai Content Areas and Mai Columns.
* Added: `./tests/setup.sh`, a throwaway test site with a smoke check, a slots check, an installer check, and a headless Site Editor check.
